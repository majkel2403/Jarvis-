# VISION — Czym jest Jarvis OS

## Definicja

**Jarvis OS** to inteligentne środowisko pracy łączące:

- **Desktop** — własny pulpit z oknami, widgetami, folderami i aplikacjami
- **Agent AI (Jev)** — warstwa decyzyjna rozumiejąca cel, kontekst i podejmująca decyzje
- **Orkiestrator (Hermes)** — koordynacja wykonania, zarządzanie narzędziami i modelami
- **Event Bus** — komunikacja między modułami w czasie rzeczywistym
- **Orb** — wizualizacja rzeczywistego stanu systemu
- **Process Log** — czytelny przebieg wykonywanych zadań

## Cel nadrzędny

Stworzyć środowisko, w którym AI może:
1. **Rozumieć kontekst** — widzieć stan systemu, pamiętać historię, znać cel
2. **Podejmować decyzje** — wybierać działania na podstawie analizy
3. **Wykonywać operacje** — nawigować, manipulować, tworzyć
4. **Weryfikować rezultaty** — sprawdzać czy działanie się powiodło
5. **Uczyć się** — adaptować na podstawie wyników

## Zasady fundamentalne

1. **Autonomia z kontrolą** — agent może działać sam, ale użytkownik zawsze nadzoruje
2. **Obserwacja przed działaniem** — żadna akcja bez zrozumienia stanu
3. **Weryfikacja po działaniu** — każdy rezultat sprawdzany
4. **Jeden źródło prawdy** — Event Bus jako system stanu
5. **Efekty jako informacja** — animacje pokazują stan, nie są ozdobą

## Rola poszczególnych komponentów

| Komponent | Odpowiedzialność |
|-----------|------------------|
| **Jarvis OS** | Środowisko, interfejs, zasoby (okna, pliki, widgety) |
| **Jev** | Rozumienie, planowanie, wybór działania, weryfikacja |
| **Hermes** | Wykonanie, orkiestracja narzędzi, zarządzanie modelami |
| **Event Bus** | Komunikacja, synchronizacja stanu |
| **Orb** | Wizualizacja stanu systemu w czasie rzeczywistym |
| **Process Log** | Historia i postęp wykonywanych zadań |

## Co Jarvis OS NIE jest

- ❌ Zwykły dashboard
- ❌ Chatbot z efektami
- ❌ Alternatywa dla systemu operacyjnego
- ❌ Narzędzie bez agenta

## Docelowy użytkownik

- Zaawansowany użytkownik AI
- Oczekuje autonomii agenta
- Potrzebuje kontroli nad zaufaniem
- Chce widzieć co agent robi i dlaczego
